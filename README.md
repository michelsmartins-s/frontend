# 💻 Trabalhos de Frontend - IFRS

Este repositório contém todos os projetos e exercícios práticos desenvolvidos durante as aulas da disciplina de Frontend no curso Técnico Integrado em Informática para Internet (IFRS - Campus Rio Grande).

O objetivo principal destes projetos é colocar em prática os conceitos de estruturação, estilização e interatividade web.

## Tecnologias Utilizadas

Durante a disciplina, utilizamos as seguintes tecnologias nestes projetos:
* **HTML5:** Semântica e estrutura.
* **CSS3:** Estilização, Flexbox, Grid e layouts responsivos.
* **JavaScript:** Lógica de programação e manipulação de elementos na tela.
